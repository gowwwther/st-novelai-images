# NovelAI Images — Till

Отдельное расширение SillyTavern для **официального NovelAI**. Основано на [SillyImages](https://github.com/0xl0cal/sillyimages): сохранены обработка тегов и extblocks, загрузка в чат, ручная перегенерация, остановка, кнопки скачивания, просмотр с зумом, профили и журнал. Других генераторов в интерфейсе нет.

## Установка

1. SillyTavern → Extensions → Install extension → `https://github.com/gowwwther/st-novelai-images`.
2. **Отключите генерацию в SillyImages / SLAYimages**, чтобы два расширения не обрабатывали один `[IMG:GEN]` одновременно. Удалять их или их настройки не нужно.
3. Перезагрузите Таверну. Откройте **NovelAI Images — Till**.
4. Вставьте Persistent API Token из NovelAI → Settings → Account → Get Persistent API Token. Endpoint закреплён: `https://image.novelai.net`.
5. Выберите V5 Full / Curated или V4.5 Full / Curated. Для своих негативов используйте Full/Curated: V5 Medium имеет фиксированный негатив.

## Персонажи

Вкладка **Библиотека → Персонажи**: сколько угодно записей. Каждая содержит имя, алиасы, внешность, личный негатив, фото, правила подбора и координаты.

ИИ выбирает **имена**, расширение добавляет внешность в `parameters.v4_prompt.caption.char_captions`. Личный негатив попадает в тот же индекс `parameters.v4_negative_prompt.caption.char_captions`. Он не добавляется к общему негативу и не должен подавлять особенности другого персонажа.

Одновременная генерация ограничена моделью: 22 текстовых слота V5 / 6 V4.5. При превышении запрос блокируется; записи библиотеки не обрезаются. Визуальное соблюдение промпта зависит от самой модели.

### Рекомендуемый тег

```html
<naicom>
<img data-iig-instruction='{"prompt":"2boys, evening garden, medium shot, talking","characters":[{"name":"Ren","prompt":"sitting, smiling"},{"name":"Gojo","prompt":"standing beside him"}],"aspect_ratio":"1:1"}' src="[IMG:GEN]" />
</naicom>
```

В `prompt` идут сцена, количество людей, взаимодействие, кадр и свет. В `characters[].prompt` — только поза, выражение и текущая одежда; внешность берётся из карточки. `characters` можно записывать и как `['Ren','Gojo']` (в JSON используйте двойные кавычки).

Сначала создайте включённые карточки с этими именами. Неизвестное имя и пустая внешность блокируют запрос, вместо тихой генерации случайного персонажа. `characters: []` означает сцену без библиотечных персонажей. Без `characters` применяется подбор по именам и алиасам из `prompt`, а также режим «Всегда».

Совместимы старые теги `[IMG:GEN:{...}]` и разделители: `сцена | Ren, sitting | Gojo, standing`. Не используйте одновременно массив `characters` и разделители `|`.

Автоматическая инструкция для ИИ включена по умолчанию. Она содержит **только имена** персонажей и стилей, без внешности. Её можно выключить и самостоятельно вставить макрос `{{nni-catalog}}` в пресет. Кнопка **Отладка → Инструкция для ИИ** показывает точный текст.

## Стили и негативы

**Библиотека → Стили**: теги художников, личный негатив стиля и необязательное фото стиля. Нажмите **Активировать**. Стиль добавляется обычным префиксом промпта, без обёртки `[STYLE: ...]`.

Общий негатив = поле «Общий негатив» + активный негативный пресет + негатив выбранного стиля + `negative_prompt` из тега (если указан). Персональные негативы остаются в отдельных слотах.

С версии **1.0.2** в **Генерации** отдельно выбираются встроенный **Undesired Content (UC) preset** сайта (None / Heavy / Light / Human Focus), **Add Quality Tags** (None / Light / Standard) и добавление `nsfw` в общий негатив. Расширение разворачивает эти пресеты в текст до отправки: UC добавляется перед своим общим негативом, Quality Tags — после общего позитива. `input` и `v4_prompt.caption.base_caption` совпадают. Персональные слоты сохраняются. В отладке видны выбранные пресеты, все добавленные теги и длины фактических слотов. Встроенные пресеты и пользовательские негативные пресеты библиотеки — отдельные настройки; их теги суммируются.

Обновление сохраняет прежнее поведение: по умолчанию встроенные пресеты **None**, дополнительный `nsfw` выключен. Настройки сохраняются в профилях подключения. V4.5 использует один набор Quality Tags для Light/Standard; Medium использует фиксированный UC. Блок `Text:` остаётся в конце промпта; Quality Tags содержат `no text`, поэтому для надписей может помочь None. Наборы тегов взяты из [Quality Tags](https://docs.novelai.net/en/image/qualitytags/) и [Undesired Content](https://docs.novelai.net/en/image/undesiredcontent/) официальной документации.

`"style":"Имя стиля"` или `"style_id":"id"` выбирают конкретный стиль для кадра. Если стиль не указан, используется активный. С версии 1.0.1 произвольное `style` вроде `cinematic` не заменяет активный библиотечный стиль: он сохраняется вместе с негативом и фото, а отладка показывает предупреждение. Если активного стиля нет, сохраняется совместимость с текстовым стилем в теге. Не вставляйте `|` в библиотечные поля: для персонажей существуют отдельные карточки.

## Фото: реальная поддержка моделей

**V5**: текстовые описания и негативы. Precise Reference / Vibe Transfer пока не включены в этом адаптере, поскольку официальная документация их поддержку V5 не заявляет.

**V4.5**:

- фото персонажа → **Character Reference** или **Character + Style**;
- фото стиля → **Style Reference (Precise)** или **Vibe Transfer**;
- Precise Reference готовится в 1024×1536 / 1472×1472 / 1536×1024 с чёрными полями без обрезки;
- Vibe кодируется через `/ai/encode-vibe`; токен кэшируется в IndexedDB по модели, изображению и Information Extracted. Повторный кадр/перезагрузка используют кэш;
- Precise Reference и Vibe Transfer нельзя совмещать в одном запросе;
- **фото не привязывается к отдельному текстовому слоту**: несколько Character Reference могут смешивать внешности. В интерфейсе и отладке это обозначено.

Чтобы фото отправлялось, включите флажок **«Отправлять это фото»** в карточке и выберите **«Отправлять фото»** в Генерации. В этом строгом режиме несовместимая модель блокирует запрос. В режиме «Только текст» фото остаются в библиотеке, а отладка перечисляет каждое неотправленное фото с причиной.

Стоимость по документации NovelAI: Precise Reference **+5 Anlas за каждое фото/кадр**. Vibe encoding — **2 Anlas** за новое кодирование; смена Information Extracted требует нового кодирования. Более четырёх Vibe добавляет **2 Anlas за каждый дополнительный Vibe/кадр**. Фото могут расходовать Anlas даже на Opus.

Размер выбирается в расширении (**Small / Normal / Big**). `aspect_ratio` тега меняет пропорции текущего кадра. `image_size: '1K'` для NovelAI ничего не меняет. V5 Medium использует 14 шагов и Euler Ancestral; свои негативы с Medium не теряются молча — такой запрос блокируется.

## Отладка и перенос

**Отладка → Повтор картинки с сайта по метаданным PNG** читает обычные `tEXt` или скрытые `stealth_pngcomp` метаданные оригинального PNG без показа/загрузки изображения. Импорт и проверка запроса не вызывают API. Кнопка генерации отправляет исходные общие и личные позитивы/негативы, seed, размеры и параметры из PNG; активный стиль и библиотечные персонажи в этом режиме не дописываются. Это отдельный тест для сравнения с сайтом, обычные чатовые настройки сохраняются. Выбери нужный вариант Full/Curated: название модели в PNG обычно содержит только семейство V5 или V4.5. Medium, Image2Image и PNG, использовавшие фото-референсы, для точного повтора блокируются — исходных изображений в метаданных нет. Серверные подписи и произвольные поля метаданных в API-запрос не передаются. Опубликованные тесты используют только нейтральные искусственные PNG и промпты.

На вкладке **Генерация** сразу видны выбранный API ID модели, параметры и активный стиль. В **Отладке** модель и стиль **последнего фактического запроса** показаны сверху вместе со временем, статусом, размером, шагами, Guidance, sampler и seed. Изменение настроек не переписывает последний запрос. `model: nai-diffusion-5-full` означает V5 Full High; `v4_prompt` и `v4_negative_prompt` — названия структуры промпта, используемой также V5, а не выбор V4. V5 отправляет фиксированный `noise_schedule: karras`, независимо от сохранённого выбора V4.5.

Для независимой проверки: **F12 → Network → generate-image → Payload**. Проверьте корневое поле `model`, `input`, `parameters.v4_prompt.caption.base_caption` и `parameters.negative_prompt`. Выбранный стиль должен входить в `input` и `base_caption`. Значения на сайте NovelAI автоматически не синхронизируются с расширением. Quality Tags, UC-пресеты, полный текст позитивов/негативов и случайный seed могут отличаться, даже при совпадении Steps/Guidance/sampler. Отправленная модель записывается из body; это не утверждение о проверке модели на стороне сервера.

- **Проверить сборку** — показывает текстовые слоты и JSON без отправки, бесплатно. Фото в этом предварительном просмотре помечены как планируемые, без кодирования.
- **Последний запрос** — фактическое тело последнего вызова API, статус, слоты, негативы, причины подбора, отправленные фото и пропущенные фото.
- **Скачать полный JSON** — полный отправленный body, включая Base64 референсов. Authorization / API-ключ в экспорт не входят.
- **Скачать логи** — журнал ошибок и повторов.
- **Экспорт / импорт** — переносит библиотеки вместе с фото. API-ключи исключены. Импорт добавляет записи, не удаляет старые.
- **Перенести из SillyImages** — копирует стили, негативные пресеты, текстовые записи лорбуков и описания из библиотеки внешности. Оригинальные настройки не изменяются. Проверьте имена/алиасы после переноса.

Перегенерация использует текущую библиотеку: поменяйте внешность/негатив и нажмите повтор. Изменённые API-настройки сохраняются автоматически; **Сохранить** фиксирует их в выбранном профиле.

## Проверка

```sh
npm install
npx playwright install chromium
npm test
npm run test:e2e
```

Тесты используют подменённые ответы API и не расходуют Anlas. Они проверяют именно тело HTTP-запроса, сохранение в чат/extblocks, повтор, отмену, фото-референсы, кэш Vibe и интерфейс. Реальная платная генерация требует ключа пользователя и проверяется после установки.
